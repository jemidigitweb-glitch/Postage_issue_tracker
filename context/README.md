# context/

## Why this folder exists

This folder holds the foundational reference content that Claude reads automatically
when this AIOS project is opened. It contains structured knowledge extracted from
Laksika's BGCT workflow documents and Janarthan's embedded rules.

## What belongs here

- Team structure and roles (team-structure.md)
- BGCT procedures structured for AI reference (bgct-procedures.md)
- Janarthan's postage rules extracted as a distinct layer (janarthan-rules.md)
- Courier and vendor relationship information (courier-vendor-info.md)
- Documentation of the Postage/Purchasing booking boundary (vendor-booking-boundary.md)

## What does NOT belong here

- Daily issues or operational log entries — those go in intelligence-inbox/daily-issues/
- Decisions or gap resolutions — those go in decisions/
- Evidence files or screenshots — those go in evidence/
- Skill files — those belong in skills/
- Invented content not traceable to Laksika's documents or a Varmen-confirmed decision
