# decisions/

## Why this folder exists

This folder records confirmed decisions that resolve gaps, clarify rules, or
establish boundaries not covered by Laksika's source documents. Every entry
here has been confirmed by Varmen (and Laksika where required) before being
treated as operational fact.

## What belongs here

One file per decision or decision batch:
- Format: YYYY-MM-DD-decision-[topic].md
- Each entry must include: date, the question or gap being resolved, the
  confirmed decision, who confirmed it (Varmen / Laksika), and which CLAUDE.md
  section or context file it affects

## What does NOT belong here

- Open gaps not yet resolved — those belong in intelligence-inbox/document-gaps/
- General notes or drafts — only confirmed decisions
- Invented resolutions — every entry must trace to a Varmen-confirmed outcome
- Daily issue entries — those belong in intelligence-inbox/daily-issues/
