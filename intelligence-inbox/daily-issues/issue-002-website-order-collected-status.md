## Evidence

**Source:** Warehouse voice recording (Issue 003) and supporting website order
shipping label image (2026-06-26), extracted and summarised via NotebookLM.

**Summary of NotebookLM findings:**

The recording confirms that website orders are being marked as "Collected" before
the physical collection has occurred. This was flagged as a recurring problem —
the same issue was raised approximately one month prior to this recording, and it
has now resurfaced with a customer reporting it again today. The speaker in the
recording identified this as requiring immediate investigation and correction.

The supporting website order shipping label image provides evidence of the order
and label in question but does not itself reveal the cause of the incorrect status
update. The root cause — whether it originates from website software behaviour,
warehouse scanning, or a system synchronisation issue — is not confirmed by the
recording or image.
