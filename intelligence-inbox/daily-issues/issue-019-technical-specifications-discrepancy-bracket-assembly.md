## Issue Summary

A measurement specification discrepancy has been identified in the context of the CRFF2404BM
240mm 4-Outlet ceiling rose (black). The photographic evidence shows a countersunk screw
component with a handwritten annotation of "3cm" (equivalent to 30mm). An audio recording
accompanying the evidence reportedly states "30cm" for the same or a related measurement.

The user has confirmed that "30cm" was a verbal mistake and that the intended value is 30mm /
3cm. The nature of the discrepancy — audio instruction vs. visual annotation — represents a
technical specification inconsistency of the type covered by the existing GAP-006 structural
control absence: no verification process to check that verbal, audio, and written technical
specifications are consistent before distribution.

The source document or context in which "30cm" was stated (whether a formal instruction,
internal communication, or verbal explanation) has not been independently confirmed from
available evidence. This must be established before the issue can be fully classified or
resolved.

## Document Gap

**Linked to existing:** gap-006-assembly-instruction-technical-sign-off-and-product-verification.md

A new Document Gap has **NOT been created** for this issue.

GAP-006 already records the absence of a documented technical sign-off and product-to-specification
verification process before assembly instructions are approved for distribution. The gap notes
explicitly that "the absence of this process means instruction errors can enter mass printing and
reach customers without any internal detection step" and that "any product with a changed
configuration or a reused template can generate the same type of error without internal
detection."

ISSUE-019 represents a new instance of the same structural control absence: a measurement value
(3cm / 30mm) was reportedly mis-stated as "30cm" in an audio instruction, and no verification
process exists to cross-check audio, verbal, and written specifications for consistency before
distribution.

**Potential gap extension (to be reviewed):** GAP-006 as currently written focuses on printed
assembly instruction sign-off. If investigation confirms that the "30cm" error exists in an
audio or verbal instruction format, the gap may require extension to explicitly cover audio and
verbal instruction accuracy verification. This determination requires the source and nature of
the "30cm" statement to be confirmed first. The reviewer should assess whether this warrants
a GAP-006 amendment or a new gap document.
