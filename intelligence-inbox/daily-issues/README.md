# intelligence-inbox/daily-issues/

## Why this folder exists

This folder captures structured daily issue log entries for Postage operations.
It formalises the existing daily issue collection process (run by Vishnu Sree
via Atis Raj) into the AIOS structure so that pattern detection can function
over time.

## What belongs here

One file per day or per issue batch, named by date:
- Format: YYYY-MM-DD-issues.md
- Each entry must include: date, issue type, description, region or courier
  affected, status, and who it was escalated to (if applicable)

## What does NOT belong here

- Resolved or processed entries — move those to intelligence-inbox/processed/
- Document gaps or source file problems — those go in intelligence-inbox/document-gaps/
- Decisions or confirmed rule changes — those go in decisions/
- Unstructured free-text notes without the required fields
