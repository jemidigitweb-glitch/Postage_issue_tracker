# intelligence-inbox/document-gaps/

## Why this folder exists

This folder captures gaps identified during the build — information that should
be in Laksika's source documents but is missing, unclear, or could not be
confirmed from the available materials. Each gap is flagged here so Varmen can
direct the resolution.

## What belongs here

One file per gap or gap batch, named descriptively:
- Format: YYYY-MM-DD-gap-[topic].md
- Each entry must include: date identified, what is missing, which workflow it
  affects, who needs to confirm it (Laksika or Varmen), and current status

## What does NOT belong here

- Daily issue entries — those go in intelligence-inbox/daily-issues/
- Confirmed and resolved gaps — once resolved, move the outcome to decisions/
- General notes or drafts not related to a specific source document gap
- Invented answers to gaps — never fill a gap without Varmen confirmation
