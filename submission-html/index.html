Add Latest Issues — Import Workflow

This dashboard is a static HTML file. New issues are imported using a local Python script.

Run this command from the project root:

python3 tools/import-issues.py

The script will:

  • Read all intelligence-inbox/daily-issues/*.md files
  • Compare against issues already in this dashboard
  • Add only new issues — never duplicates
  • Verify evidence images before attaching them
  • Report what was added and what was skipped

After running the script, reload this page to see new issues.
