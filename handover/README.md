# handover/

## Why this folder exists

This folder documents Vishnu Sree's build progress so the eventual owner of this
AIOS can take over without losing context. It applies the Unknown Developer Test:
everything needed to understand and continue this project must be findable here
without needing to ask the original builder.

## What belongs here

- Daily closure notes written by Vishnu Sree at the end of each work session
- A running build log recording what was completed, what evidence was saved, and
  what gaps remain for Varmen
- A final handover document prepared before the AIOS is handed to its eventual
  owner (likely Laksika or her designate, to be confirmed at Phase 4)

## What does NOT belong here

- Operational knowledge or procedures — those belong in context/
- Evidence files — those belong in evidence/
- Active issues — those belong in intelligence-inbox/daily-issues/
- Anything that belongs in a different folder (handover documents only)
