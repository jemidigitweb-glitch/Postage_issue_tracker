# evidence/

## Why this folder exists

This folder stores evidence that confirms work was completed correctly —
screenshots, exported reports, validation outputs, and file confirmations.
It supports the audit trail required by the AIOS governance model.

## What belongs here

- Screenshots confirming booking completion or system state
- Label count confirmations and packlist file records
- Validation report outputs from each build phase
- MCP import confirmations and verification reports
- Any other file that proves a task was completed as documented

## What does NOT belong here

- Source workflow documents — those remain in the Postage source folder
- Context knowledge files — those belong in context/
- Operational log entries — those belong in intelligence-inbox/daily-issues/
- Skill definitions — those belong in skills/
